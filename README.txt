FUTURE LEADERS WEBSITE
======================

Files:
- index.html  Main website content
- styles.css  Responsive styling and layout
- script.js   Mobile navigation and automatic copyright year

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view the website in your browser.

HOW TO EDIT
- Update text and sections in index.html.
- Change colours, fonts and spacing in styles.css.
- Update navigation behaviour in script.js.

The contact links use the email addresses and phone numbers supplied in the
company profile. Social media profile URLs were not supplied, so no unverified
social links have been added. Google Fonts requires an internet connection;
the site otherwise works as a local static website.
